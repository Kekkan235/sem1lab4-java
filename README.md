# Лабораторная работа: Геометрические фигуры

Автор: Нарольский МВ
Группа: ФИТ-251

## Описание

Программа работает с геометрическими фигурами.
Вычисляет площади, периметры и объём цилиндра.

## Используемые технологии

- Java JDK 25
- Интерфейсы
- Собственные исключения
- Java IO
- Сериализация

## Формат текстового файла

C;5 — круг с радиусом 5.

R;4;6 — прямоугольник со сторонами 4 и 6.

## Обработка ошибок

При обнаружении неправильной строки
загрузка списка прекращается.
Выводится номер строки и причина ошибки.

## Запуск

В аргументах программы указываются:

1. Путь к входному текстовому файлу.
2. Путь к выходному бинарному файлу.
